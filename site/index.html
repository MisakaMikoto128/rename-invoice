安装指南

程序 2 account-manager — 双击即用

  1. 下载 AccountManager.exe（约 106 MB）。
  2. 双击运行。第一次启动需要 5-10 秒（应用在解包）。
  3. 若弹出 Windows SmartScreen 警告（"Windows 已保护你的电脑"）：点 更多信息 → 仍要运行。exe 没有购买代码签名证书，不是病毒。个别杀毒软件误报 PyInstaller 打包的程序，加白名单即可。
数据存放位置（备份只需要拷走这一个文件夹）： 数据库 %APPDATA%\rename-invoice\accounts.db（SQLite）、 项目 PDF %APPDATA%\rename-invoice\projects\、 设置 %APPDATA%\rename-invoice\settings.json。 卸载 = 删 exe + 上述文件夹，注册表零残留。

程序 1 invoice-cli — 三步安装

前提条件

  • Windows 10 / 11
  • Python 3.8+ 已安装并在 PATH 里（python --version 能出版本号）
  1. 获取源码： 
    git clone https://github.com/MisakaMikoto128/rename-invoice.git
cd rename-invoice/apps/cli
  2. 安装依赖（pymupdf 解析 PDF + openpyxl 导出 Excel）： 
    pip install -r requirements.txt
  3. （可选）注册经典右键菜单 — 双击 install_context.bat，回答两个独立问题（直接回车 = 否）：
    汇总窗口？Excel 汇总？右键后的行为
    NN纯静默，结果只写审计日志（推荐默认）
    YN静默 + 处理完弹汇总窗口
    NY静默 + 生成 发票汇总_时间戳.xlsx
    YY汇总窗口 + Excel 汇总都开启
    想换组合，随时再双击一次 install_context.bat 即可。卸载用 uninstall_context.bat。
不要移动仓库目录 — 右键菜单注册的是绝对路径。必须移动时： 先 uninstall_context.bat → 移动 → 新位置重跑 install_context.bat。

Rust 绿色版（单 exe，免 Python）的构建与用法见仓库 apps/cli/rust/README.md。

程序 3 explorer-extension — 一条命令装进 Win11 右键菜单

前提条件

  • Windows 11 21H2+（build 22000+，没有现代右键菜单的老系统用程序 1 即可）
  • Python（作为右键菜单的处理器；或用 -CliExe 指定独立 exe）
  • Rust 工具链（仅首次构建 DLL 时）+ Windows SDK（makeappx / signtool）
  1. 一键安装： 
    cd rename-invoice\apps\explorer-extension\scripts
.\install.ps1
    脚本自动完成：构建 DLL → 写注册表 CLI 配置 → 打包 → 注册稀疏 MSIX 包。
  2. 注册方式二选一（脚本自动判断）：
    • 开发者模式开启（设置 → 隐私和安全性 → 开发者选项）：直接注册，免签名、免证书、免 UAC。
    • 未开启：自动生成自签证书 CN=rename-invoice 并签名，导入 TrustedPeople 时弹一次 UAC。
  3. 验证：右键任意 PDF 或文件夹 — 现代菜单顶层出现 添加发票价格前缀（带图标）。看不到时重启一次 explorer.exe 或重开资源管理器窗口。

卸载：.\uninstall.ps1（加 -RemoveCert 连证书一起清掉）。与程序 1 的经典菜单可共存；仓库移动后需重跑 install.ps1。

使用指南

程序 1 invoice-cli

方式 A · 拖放

把 PDF 或整个文件夹拖到 rename_invoice.bat 上。拖文件夹 = 处理其中所有 PDF（不含子目录）。支持中文、空格路径。

方式 B · 经典右键菜单

在 PDF 文件（可多选）、文件夹图标、文件夹空白处右键 → 添加发票价格前缀。Windows 11 需点"显示更多选项"（或按 Shift+F10）。多选 N 个文件由文件锁合并为一次处理，只产生一条日志批次。

方式 C · 双击当前目录

把 rename_invoice.bat（或快捷方式）放进报销文件夹，双击即扫描本目录全部 PDF。已加前缀的文件自动跳过 — 重复双击无副作用。

命令行参考

python rename_invoice.py "D:\报销\7月"
python rename_invoice.py 发票1.pdf 发票2.pdf
pythonw rename_invoice.py --silent --summary --xlsx "D:\报销\7月"

--silent 静默队列（右键菜单内部用的就是它）；--summary 处理完弹汇总窗口；--xlsx 在目标文件夹生成带合计公式的 发票汇总_时间戳.xlsx。

处理结果：成功 → 文件名加 98.01元- 前缀；已有前缀 → 跳过； 校验不过 → 保持原名不动，红色提示原因，记入审计日志 apps/cli/rename_invoice.log（含成功/失败/跳过全记录，可反查）。

程序 2 account-manager

  1. 新建项目 — 主窗口左上角"+ 新建项目" → 输入项目名（比如"11月报销"）→ 自动创建文件夹。每个报销批次建议一个项目。
  2. 导入 PDF — 进入项目 →"+ 导入 PDF"或"导入文件夹"批量导入。自动提取发票号 / 开票日期 / 销售方 / 金额，按发票号去重；也支持无 PDF 的手工录入。
  3. 编辑跟踪 — 表格点单元格直接改备注 / 淘宝单号 / 金额；状态下拉切换 未报销 / 报销中 / 已报销；状态 chips 一键过滤；备注或单号空着的行有黄色提醒。
  4. 导出 —"导出 xlsx"（合计是公式，改金额自动重算，人民币货币格式）或"导出 zip"（打包全部 PDF + 可选 Excel）。备注 / 淘宝单号两列留空列手填。

另有跨项目全局搜索、项目回收站（软删除可恢复）、黑暗模式、窗口大小记忆、PDF 存储位置迁移（⚙️ 设置）。

程序 3 explorer-extension

装好后没有界面 — 它活在右键菜单里：

  • 右键 PDF（可多选） → 顶层 添加发票价格前缀 → 全部选中项一次处理。
  • 右键文件夹 / 空白处 → 处理该文件夹下所有 PDF。
  • 选中项里没有任何 PDF 或文件夹时，命令自动从菜单隐藏，不碍眼。
  • 处理结果与程序 1 完全一致（同一个 CLI、同一份审计日志）。

可靠性：为什么敢用在报销文件上

金额错认就是真金白银的损失（98.01 看成 980.10 就是事故）。每张发票必须通过三层校验，任何一层不确定就拒绝重命名。

1

双重金额一致性

每张增值税发票都有两个法律等价的金额：价税合计（小写）¥98.01 与 价税合计（大写）玖拾捌圆零壹分。工具同时提取两者，要求精确匹配（容差 0.005 元，等同到分精确比对）。

2

最大值检查

价税合计 = 金额 + 税额，必然是票面最大的 ¥ 值。若大写转换值不是最大 ¥ 值，说明可能错认到了"金额"或"税额"行 — 拒绝重命名。

3

失败安全

大写缺失 / 解析失败 / 数字不匹配 / 文件被占用 → 一律保留原文件名 + 记审计日志。目标文件名已存在时追加 (2)、(3)，绝不覆盖。不集成 OCR — 扫描件识别错误会破坏可靠性（先自行 OCR 成可搜索 PDF 再处理）。

中文大写金额解析器覆盖 玖拾捌圆零壹分 到 壹亿圆整 等 15 类格式（单元测试）；全部 109 个测试由 CI 在 Windows 上自动执行。

常见问题

能处理扫描件（图片 PDF）吗？

不能。先用 OCR 工具把扫描件转成可搜索 PDF。设计上故意不集成 OCR — OCR 识别错误会破坏金额可靠性。

支持哪些发票类型？

增值税专票 / 普票 / 电子普票都可以，只要票面有"价税合计（大写）"和 ¥XX.XX 字段。一个 PDF 里合并多张发票时只识别第一张，建议先拆分。

右键之后什么都没发生，是坏了吗？

默认是纯静默模式。先看文件名有没有加前缀；再看审计日志 apps/cli/rename_invoice.log。想每次弹窗确认结果，重跑 install_context.bat 把"汇总窗口"选 Y。

Windows 11 右键菜单里找不到（程序 1）？

经典菜单在"显示更多选项"里（或按 Shift+F10）。想要顶层直达，安装程序 3（explorer-extension）。

想撤销重命名 / 修改命名规则？

撤销：前缀只是文件名前缀，手动去掉即可；审计日志里有每一条 原名 → 新名 记录可反查。改名规则：改 rename_invoice.py 的 new_name = f'{amount_str}元-{name}'，并同步 ALREADY_PREFIXED_RE 正则，否则会重复加前缀。

SmartScreen / 杀毒软件报警？

exe 未购买代码签名证书，首次运行点"更多信息 → 仍要运行"；杀软误报 PyInstaller 打包程序时加白名单。介意的话可以从源码自己构建（全部开源）。

数据会上传吗？断网能用吗？

100% 离线，零联网，无遥测。数据库和 PDF 全在本机，断网一切功能可用。

发票提取错了怎么办？

先在 PDF 阅读器里对照"价税合计"确认确实错了，再到 GitHub 提 issue 并附脱敏后的样本（公司名、号码可涂黑，金额字段保留），我们修提取算法。

故障排查

现象处理
双击 .bat 一闪而过Python 未装或不在 PATH。命令行手动跑 python rename_invoice.py 看报错。
右键菜单没有出现Win11 点"显示更多选项"；重跑 install_context.bat；检查注册表 HKCU\...\SystemFileAssociations\.pdf\shell\AddInvoicePrice。
失败：PDF 无文字层扫描件。先用 OCR 转可搜索 PDF。
失败：中文大写金额与 ¥ 值不匹配非标准版式或文本提取错乱。PDF 阅读器里人工核对后手动改名，欢迎提 issue 附脱敏样本。
失败：重命名失败文件被占用（被 PDF 阅读器打开）。关闭后重试。
插件装完菜单没出现重启 explorer.exe 或重开资源管理器窗口；确认 Get-AppxPackage rename-invoice-ext 已注册。
